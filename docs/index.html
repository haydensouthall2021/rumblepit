How a coin gets here

Four steps, and the first one is the only one you have to do.

1

Launch here

Name, ticker, image. It trades on a bonding curve straight away and shows up on Axiom, DexScreener and every terminal from the first trade.

2

Pick a league

Choose which game your coin fights in. That choice is made at launch, so your fees route to the right pot from trade one.

3

Fees fill the pot

Every trade pays into the league's shared pot automatically. Nobody has to claim anything or remember to forward it.

4

Holders fight

Holders burn the coin to score for it. Every six hours the top coin wins, and its biggest burner is paid — in the same transaction.

Where every lamport goes

No hidden cuts, no discretion, no wallet that can be quietly emptied. This is the whole split, and it's the same split the program enforces.

Don't trust us. Check.

Every claim here is a property of deployed code, not a promise. Each one is checkable in the source or on an explorer in under a minute.

Nobody holds a pot

Every league's pot sits at an address derived from the program itself. No private key exists for it — not ours, not anyone's.

pot addressprogram-derived
✓

Payout needs no permission

When a round ends anyone can trigger the payout, and the code decides who's paid. Pass the wrong winner and the transaction fails rather than mispaying.

settlepermissionless
✓

We can't hide the winner

Settling requires every pool in the league, checked exactly once. Nobody can leave out the winning pool to hand the pot to second place.

all pools requiredenforced
✓

Fees are capped in code

Our cut of pot deposits can never exceed 10%. The program rejects anything higher. We could not raise it later if we wanted to.

platform cap10% max
✓

Liquidity is burned

Our launchpad config sets 100% burn at graduation — Raydium's own description is "strict no-insiders launches." It's readable on-chain.

Pausing can't trap money

We can stop new leagues and joins. We cannot stop a payout — the settle instruction doesn't even read the pause flag.

Where this actually is

The program is written and builds clean. It is not audited and not yet deployed to mainnet. Early launches will be small, run by us, and tested with our own money before anyone else's goes in. We'd rather tell you that here than have you find it.
